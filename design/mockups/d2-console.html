So You Want to Get an Espresso Machine?

2023-05-2112 min2,410 words#coffee #review
outline
  1. just don't do it
  2. types of espresso machines
  3. the grinder problem
  4. what to actually buy

If you're wondering whether you should get an espresso machine, just don't. Making quality espresso at home is far more difficult than drip coffee, and you'll have to deep-dive into coffee nerd-dom to get anywhere near what your local third-wave shop serves.[1]

types of espresso machines

Four categories are worth knowing about, and the differences matter far more than the badge on the front. Price tracks control, not quality — a $2,000 super-automatic will lose to a $400 lever in the right hands.

semi automatic

You control the grind, dose, tamp and shot time; the machine controls the water. Start here. A 58mm bottomless portafilter will tell you the truth about your technique.[2]

the grinder problem

Buy the grinder first. Here's the ratio I use to work out whether a shot was under- or over-extracted:

brew-ratio.ts
// grams in → grams out, over timeexport function brewRatio(dose, out, seconds) {  const ratio = out / dose;  if (ratio < 1.5) return 'ristretto';  if (ratio > 2.5) return 'lungo';  return seconds < 22 ? 'under' : 'dialled in';}

Everyone who ignores this buys the grinder second, at twice the price.

footnotes
  1. Third wave being the one where they ask which farm you'd like. ↩
  2. Channelling is impossible to hide once the basket is open. ↩

spacing & motion

  • 4px base: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. Gutter clamp(16px, 10px + 2vw, 32px), section clamp(48px, 28px + 4.5vw, 96px).
  • Radius 6px, 1px borders, 1px hard offset shadow on buttons only — no blur anywhere.
  • Motion budget: blinking caret in the hero, 1px button lift, row and code-line hover fills, panel border colour on hover. Nothing moves on scroll. All suppressed under prefers-reduced-motion.
  • The faint 32px grid behind the hero is masked to a radial fade so it never tiles across the whole page.

structure

  • Homepage is the résumé scroll: hero → at a glance → experience (as a deploy log) → projects (repo cards) → writing. About is its own page.
  • Nav is home / projects / writing / about, styled as paths. Lists is a tab inside writing. Breadcrumbs on every sub-page.
  • Post template: 40rem measure, outline panel, footnotes with back-links, code in a titled panel with a line-number gutter — Astro's built-in Shiki does the real highlighting, with remark-gfm and remark-footnotes.
  • The ⌘K chip in the header is decorative here; if you want it real it's a small Astro island over a static index — the only JS island on the site.

mobile & dark mode

  • Bottom tab bar, four items, 60px tall plus env(safe-area-inset-bottom), active tab marked with an amber top border rather than a colour change alone.
  • Single column below 800px; the case-study rail drops under the body; the code gutter scrolls horizontally inside its panel rather than widening the page.
  • Portrait swap: hover on desktop, tap on touch. The scanline overlay is CSS only.
  • html[data-theme] + blocking head script, localStorage over prefers-color-scheme; dead html.dark deleted.
